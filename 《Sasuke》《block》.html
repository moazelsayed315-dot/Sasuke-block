How To Play

🎮 Drag and Drop the current block onto the 8x8 grid to place it.

🔥 Complete a full row or column to clear it from the board and earn points.

⚡ Use the "Rotate" button to change the orientation of the current block before placing it.

💀 The game ends when there is no space to place the current block.
